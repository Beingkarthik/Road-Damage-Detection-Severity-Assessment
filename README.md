# Road Damage Detection & Severity Assessment

## Overview
A deep learning project to detect road damage in images.

## Dataset
RDD2022 - Road Damage Detection Dataset.

## Planned Features
- Road damage detection
- Bounding box localization
- Model evaluation
- Severity assessment using a validated method

## Technologies
- Python
- OpenCV
- PyTorch
- YOLO
